# 쓸데있는 선물 교환

비씨카드 2025 하반기 입사 동기 16명 · 12월 5일 MT. React + TypeScript + Vite로 만든 정적 사이트이며 DB나 서버 환경변수가 필요하지 않습니다.

## 로컬 실행

```sh
npm install
npm run dev
```

일반 주소에서는 행사 초대장을, 개인 링크에서는 해당 사람의 선물 상대를 확인할 수 있습니다. 링크의 `#` 이후까지 모두 전달해야 합니다.

## 고정 매칭과 링크

이 프로젝트의 최초 매칭은 이미 생성되어 있습니다. **빌드나 재배포할 때 다시 추첨하지 마세요.** 초기화 명령 `npm run draw:init`은 기존 결과가 있으면 중단합니다.

- `public/results/`: 공개 배포 가능한 AES-256-GCM 암호화 결과입니다. Git에 포함해 고정 결과를 유지합니다.
- `.private/delivery.json`: 참가자 이름, 무작위 결과 ID, 개인 해독 키가 있습니다. 상대 이름은 없습니다. Git과 Vercel 배포에서 제외됩니다.
- `.private/links.txt`: 직접 전달할 참가자별 링크 목록입니다. 공개 배포하지 마세요.

**`.private` 폴더는 별도로 안전하게 백업하세요.** 다른 PC나 Git 클론에는 이 파일이 없습니다. 분실하면 기존 개인 링크를 재발급하거나 사진을 교체할 수 없습니다. 운영자가 전체 링크를 보유하므로 다른 사람의 링크를 열면 그 결과를 볼 수 있는 운영 방식입니다.

개발용 링크 목록 생성:

```sh
npm run links -- http://localhost:5173
```

결과나 링크 비밀 키는 터미널에 출력하지 않습니다. `.private/links.txt`를 로컬에서 열어 이름에 맞는 링크를 개별 전달하세요. 링크를 가진 누구나 결과를 볼 수 있으며, 로그인이나 열람 집계는 없습니다. 해독 키는 URL fragment에 있으므로 웹 요청에는 포함되지 않습니다. 외부 분석 도구나 외부 이미지 요청도 사용하지 않습니다.

## Vercel 배포

1. 프로젝트를 Git 저장소에 올립니다. `.private` 폴더가 제외되는지 확인하세요. `public/results`의 16개 암호화 파일과 `package-lock.json`은 포함합니다.
2. Vercel에서 저장소를 Import합니다. 프레임워크는 Vite, 빌드 명령은 `npm run build`, 출력 폴더는 `dist`입니다. 환경변수는 필요 없습니다.
3. 동기들이 로그인 없이 접속하도록 운영 배포 주소의 접근 설정을 확인합니다. 공유에는 변경될 수 있는 미리보기 주소 대신 운영 주소를 사용합니다.
4. 배포 후 아래 명령에 실제 주소를 넣어 실행합니다.

```sh
npm run links -- https://YOUR-PROJECT.vercel.app
```

주소만 바뀌며 기존 매칭과 키는 유지됩니다. `.private/links.txt`의 링크를 각자에게 전달하세요. Vercel CLI로 배포해도 `.vercelignore`가 비밀 파일을 업로드에서 제외합니다. 다른 배포 도구를 사용할 때도 `.private`는 업로드하지 마세요.

## 실제 사진 넣기

프로젝트 외부의 폴더에 `구본혁.jpg`, `김서하.png`처럼 **정확한 참가자 이름**으로 사진을 준비합니다. JPG/JPEG/PNG/WebP, 파일당 2MB 이하를 지원합니다. 정사각형 또는 얼굴이 가운데에 있는 사진이 좋습니다. 일부 사람의 사진만 제공해도 됩니다.

```sh
npm run photos:update -- /absolute/path/to/photos
npm run build
```

스크립트가 기존 결과를 메모리에서 해독해 해당 상대 사진만 교체하고 다시 암호화합니다. 전체 매칭은 출력하지 않으며 개인 링크와 상대는 그대로 유지됩니다. 제공하지 않은 사진은 기존 이미지를 유지합니다. 갱신된 `public/results` 파일을 커밋하고 재배포하면 적용됩니다. 원본 사진은 `public`에 넣지 마세요.

## 검증

```sh
npm test
npm run build
```

1,000회 추첨 제약 검증, 개인 링크 파싱, 암호화/변조 방지, 사진 크기 처리, 현재 저장된 16개 링크의 고정 결과를 검사합니다. 실제 매칭은 테스트 출력에도 표시하지 않습니다. 마지막 검증은 `.private/delivery.json`이 있는 운영자 PC에서 실행합니다. 빌드는 이 파일 없이도 가능합니다.

공개 연출은 상자 흔들림 → 뚜껑 열림과 빛 → 프로필 카드와 종이꽃입니다. 모션 줄이기 설정에서는 즉시 공개합니다. 실제 사진이 없는 사람은 기본 프로필 일러스트를 표시합니다.
